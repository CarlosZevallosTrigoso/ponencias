# Ponencia de ejemplo

Este archivo existe para comprobar que la publicación funciona. Cuando subas tus propias ponencias, puedes borrarlo.

## Cómo agregar una ponencia

Sube un archivo `.md` a la carpeta `ponencias/` del repositorio. Aparece en la lista uno o dos minutos después de publicar. El título que se muestra es el primer encabezado de nivel 1 del archivo; si no tiene, se usa el nombre del archivo.

El archivo no debe empezar con un bloque de *front matter* (`---`), porque GitHub Pages lo convertiría en una página HTML y dejaría de estar disponible como `.md`.

## Cómo anotar

Selecciona un pasaje y pulsa **anotar**. Cada anotación admite varios comentarios. Las notas se guardan en este navegador, una colección por ponencia, y se vuelven a ubicar solas si el texto cambia. Para llevarlas a otro equipo, usa **exportar .json** y luego **cargar .json** en el otro navegador.

> Si un pasaje anotado desaparece del texto, la nota se conserva como *sin anclar* y vuelve a su lugar si el pasaje reaparece.
