# anotaciones

Aquí van los `.json` que exporta el lector, con el mismo nombre que la ponencia:

- `ponencias/semiosis.md` → `anotaciones/semiosis.json`
- `ponencias/2026/coloquio.md` → `anotaciones/2026/coloquio.json`

Al abrir una ponencia, el lector une estas notas con las que ya tenga el navegador. Si subes una versión nueva del `.json`, se vuelve a unir. Mientras el archivo no cambie, lo que borres en un equipo no reaparece en ese equipo.
